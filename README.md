# GLP-1 식사 부담 확인 웹 MVP

## 구조
- index.html
- css/style.css
- js/script.js

## 실행
`index.html`을 Chrome 또는 Edge에서 열면 됩니다.

별도 API, 서버, Google Sheets, 결제 기능은 사용하지 않습니다.

## UI 디자인 방향
- 분위기: 의료적 판단을 내리는 서비스처럼 보이지 않으면서 차분하고 신뢰감 있는 웰니스 서비스
- 대표 색상: 자연스러운 그린 계열
- 폰트: Pretendard 우선, 시스템 기본 글꼴 fallback
- 기존 MVP의 입력 → 결과 → 피드백 흐름은 유지
